Detailed Description

Logging library with printf formatting, multiple sinks, logging levels, etc.

You can use the STM32T::Log::Logger class to create a "static" or "dynamic" logger. Each logger has a level, a name, a timestamp formatter, and one or more outputs (sinks). They also support printf-style formatting (+ "b"/"B" for binary formatting).

The output format of loggers is currently fixed:

[Timestamp][Level][Module name (if present)]: Log message

Examples: Log_Static_Example.cpp, Log_Dynamic_Example.cpp

Default logger

There is always a default static logger which is disabled. If you don't need multiple logging modules or simply want a main logging module, you can use the default logger.

You can use the STM32T_DEFAULT_LOG_XXX macros to change the attributes of the default logger (including setting the level to something other than STM32T::Log::Level::None which enables the logger).

Example: Log_Default_Example.cpp

See also
Default logger macros

Default outputs

The outputs of a logger must be of type STM32T::Log::output_t.

See also
Predefined logger outputs

By default all loggers use STM32T::Log::default_output_stdout as their only sink. You can of course use your own custom output (e.g. to log to an SD card).
