STM32 Tools

STM32T is a framework of useful utilities for working with STM32 microcontrollers. Although some of the code might be usable with other microcontrollers (or just as a standalone library), it was mainly written to help with STM32 development.

It is written in C++17 and is meant for Keil µVision (MDK-ARM) projects generated by STM32CubeMX. It might not be usable with STM32CubeIDE or other IDEs. It relies on some HAL functions and typedefs.

What's in it

Modules (directories)

  • Core: Core utilities that aren't dependent on other modules or header files in this framework
  • Display: For using different types of display
  • GSM: For using GSM modules
  • 1-Wire: For working with 1-wire sensors
  • Memory: For working with memory ICs
  • Experimental: Might change substantially or be removed entirely
    • RFID: For working with RFID ICs and modules

Standalone headers

  • Log.hpp: Logging library with printf formatting, multiple sinks, logging levels, etc.
  • Versioning.hpp: A simplified implementation of Semantic Versioning
  • Retarget.hpp: For redirecting stdout, stderr, etc. to custom handlers
  • Error Checking.hpp: CRC and Hamming code calculation
  • IO.hpp: Simple classes for manipulating GPIO pins
  • Runnable.hpp: Simple task scheduler
  • Prof.hpp

How to use

Clone the repository as a submodule into your project (e.g. in Project-Dir/Tools) and then include the headers you need (e.g. <Tools/Core/Utils.hpp>).
