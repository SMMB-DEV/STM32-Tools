◆ STM32T_GSM_URC_SUPPORT

#define STM32T_GSM_URC_SUPPORT

Define to enable URC support for GSM.

The GSM instance can receive and store URCs sent by the GSM module to be handled later by calling STM32T::GSM::HandleURCs.

Note
DMA for UART RX must be enabled and register callbacks for UART must be enabled (USE_HAL_UART_REGISTER_CALLBACKS == 1) for this macro to have any effect.
