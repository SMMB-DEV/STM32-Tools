enum class STM32T::Log::Level : uint8_t
strong

Specifies the logging level.

Messages are displayed up to the set level. For example a logger with Level::Warning doesn't show Level::Info messages.

Enumerator
None 

Disables the logger.

Fatal 

For unrecoverable conditions (calls the fatal handler).

Error 

For errors (calls the error handler).

Warning 

For warnings.

Info 

For general information.

Debug 

For debug messages (usually not shown to the user).
