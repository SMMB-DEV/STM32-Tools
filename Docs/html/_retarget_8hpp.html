Detailed Description

Retargeting

Logs can be redirected to many different sinks including stdout. stdout, stderr, and ttywrch can also be independently redirected to multiple sinks (except themselves of course).

Other libraries and frameworks might simply use printf for logging. Or for example, the <cassert> library writes an error message to stderr when an assert fails. By using this header you can redirect logs and error messages from other libraries to the same sinks as your normal logs.
